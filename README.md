# English Tutor

Личный проект изучения английской грамматики. Claude выступает тьютором: генерирует
уроки, проводит упражнения и тесты в чате, проверяет ответы и ведёт прогресс.
Уровень ученика — B1–B2, объяснения на русском, примеры на английском.

## Как проходит занятие

Один урок = одна тема из учебного плана:

1. **Теория** — кратко, максимум страница; развёрнутое объяснение — по запросу.
2. **Упражнения** — 15–20 заданий в чате порциями по 5, с мгновенным разбором.
3. **Итоговый тест** — 10 вопросов без подсказок. Порог 8/10, ниже — тема уходит
   на повторение.

Каждые 3 пройденные темы — сессия повторения по реальным ошибкам из журнала.
Ошибка удаляется после двух правильных ответов подряд.

## Структура

```
CLAUDE.md        # инструкции тьютора: формат урока, правила проверки
state.md         # текущее состояние: тема, этап, счёт — для восстановления сессии
curriculum.md    # учебный план: 12 модулей, 44 темы, статусы прохождения
progress.md      # журнал занятий: дата, тема, результаты
mistakes.md      # журнал ошибок — сырьё для сессий повторения
lessons/         # уроки: NN-module/NN-topic.md (теория, упражнения, разбор)
docs/            # дизайн проекта
```

## Как начать

Открыть сессию Claude Code в папке проекта и сказать «начинаем». Тьютор посмотрит
`curriculum.md` и `progress.md`, скажет, где ты остановился, и предложит следующий
шаг — новую тему или повторение.
