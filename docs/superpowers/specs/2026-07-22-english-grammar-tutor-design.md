# Дизайн: проект изучения английской грамматики

Дата: 2026-07-22

## Что это

Репозиторий с учебными материалами по английской грамматике, где Claude выступает тьютором:
генерирует уроки, проводит упражнения и тесты в чате, проверяет ответы и ведёт прогресс.
Никакого кода — только markdown.

## Ученик

Носитель русского, уровень B1–B2. Объяснения на русском, примеры на английском.

## Ключевые решения

- **Схема урока — классическая**: краткая теория → упражнения → итоговый тест.
- **Теория краткая по умолчанию** (максимум страница), развёрнутая — по запросу.
- **Ответы в чате**: ученик отвечает в диалоге, тьютор сразу проверяет и разбирает.
- **Организация тем — по грамматическим модулям** (аспектам), внутри и между модулями
  от простого к сложному. Вариант «по уровням B1→B2→C1» отклонён: аспект размазывается
  по ступеням, системной картины не возникает.

## Учебный план: 12 модулей

1. Основы предложения и базовые времена
2. Перфектные времена
3. Согласование времён и косвенная речь
4. Модальные глаголы
5. Условные предложения и wish
6. Пассивный залог
7. Артикли и существительные
8. Герундий и инфинитив
9. Относительные придаточные
10. Прилагательные, наречия, сравнение
11. Предлоги и фразовые глаголы
12. Сложный синтаксис (B2+)

Полный список тем по модулям — в `curriculum.md`.

## Структура файлов

```
english-tutor/

├── curriculum.md    # план из 12 модулей со статусами тем
├── progress.md      # журнал занятий: дата, тема, результат теста
├── mistakes.md      # журнал ошибок — сырьё для сессий повторения
└── lessons/
    └── NN-module/NN-topic.md   # один файл = одна тема
```

## Формат урока

1. **Теория** — правило, 5–7 примеров, типичные ошибки русскоязычных.
2. **Упражнения** — 15–20 заданий в чате порциями по 5: раскрыть скобки, выбор варианта,
   найти ошибку, перевод с русского.
3. **Итоговый тест** — 10 вопросов в чате без подсказок. Порог 8/10, ниже — статус
   «на повторение».

После занятия тьютор дописывает в файл урока раздел «Разбор», обновляет `curriculum.md`,
`progress.md`, `mistakes.md` и коммитит.

## Повторение

Каждые 3 пройденные темы — сессия повторения: 10 вопросов из реальных ошибок в
`mistakes.md`. Ошибка, отвеченная правильно дважды подряд, удаляется из журнала.
