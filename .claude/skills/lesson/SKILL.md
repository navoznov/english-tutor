# Проведение урока

Один урок = одна тема из `curriculum.md`. Формат согласован с учеником: классическая
схема — краткая теория → упражнения → тест, все ответы в чате. Правила CLAUDE.md
действуют всегда: объяснения по-русски, надиктованная кириллица расшифровывается
и оценивается по содержанию, состояние — в `personal/state.md`. Всё личное (результаты, ошибки, разборы)
пишется только в `personal/` — эта папка не коммитится.

## 1. Определи, откуда начинать

1. Прочитай `personal/state.md`. Если урок уже идёт — продолжи ровно с «Следующего шага»:
   не начинай тему заново и не пересоздавай файл урока.
2. Если статус «между уроками»: тема — из слов ученика, а если не указана —
   первая тема без статуса в `personal/progress.md` (порядок тем — `curriculum.md`). Если по счётчику пора сессия повторения (после
   каждой 3-й пройденной темы) — сначала предложи её; решает ученик.

## 2. Создай файл урока

Путь: `lessons/NN-module/NN-topic.md` (номера — из `curriculum.md`).
Образцы формата — пройденные уроки в `lessons/`. Скелет:

```markdown
# <номер> <название>
## Теория          ← максимум страница
## Упражнения      ← 4 блока (A–D) по 4–5 заданий, всего 15–20
## Итоговый тест   ← «Проводится в чате после упражнений, 10 вопросов, порог 8/10.»
```

Разбор в файл урока не пишется — он идёт в `personal/reviews/NN-module/NN-topic.md`.

**Теория:** правило и форма, 5–7 живых примеров, маркеры-подсказки, и обязательно —
«почему русскоязычным сложно»: кальки с русского, таблица «калька → правильно».
Этот раздел — главная ценность теории; пиши его про реальные ловушки, а не для
галочки.

**Упражнения:** от механики к тонкостям. Блок A — базовое применение, B–C —
вариации (отрицания, поиск ошибок, переводы), D — самое коварное (смена смысла,
исключения). Типы вперемешку: раскрыть скобки, выбор варианта, найти и исправить
ошибку, перевод с русского. Вплети 1–2 задания, задевающие записи из
`personal/mistakes.md`, — так рецидивы всплывают раньше, чем на сессии повторения.

## 3. Проведи урок в чате

1. Выдай теорию «за 2 минуты» — сжатую версию из файла, не копию. Сразу за ней —
   блок A.
2. Упражнения — порциями по 5, блок за блоком. При проверке ответов:
   - ошибками считай только промахи **по теме урока**; всё остальное (например,
     артикли до модуля 7) — заметки: скажи о них, но балл не снижай;
   - каждый ❌ разбирай сразу: что не так, какое правило, верный вариант;
   - если ошибка повторяет запись в `personal/mistakes.md` — прямо скажи, что это рецидив.
3. **После проверки каждого блока обнови `personal/state.md`**: этап, счёт, ошибки
   с пояснениями, точный следующий шаг («выдать блок C, №11–15»). Сессия может
   оборваться в любой момент — `personal/state.md` единственное, по чему следующая сессия
   продолжит с места обрыва.
4. **Список заданий — всегда последним в сообщении.** Сначала разбор предыдущего
   блока, потом запись в `personal/state.md`, и только затем вопросы. Ученик отвечает
   с последнего экрана: если после вопросов идёт вывод инструментов или разбор,
   ему приходится скроллить вверх, чтобы их найти. Это же касается теории,
   итогового теста и любых заданий — текст с вопросами закрывает сообщение.
5. Расширенную теорию давай по первому запросу ученика, не откладывая на потом.

## 4. Итоговый тест

10 вопросов одним списком, без подглядывания в теорию. Покрой все разделы темы
и обязательно задень места, где ученик ошибался в упражнениях, — тест должен
проверить, что разбор сработал. Порог 8/10; ниже — тема получает статус
«на повторение» 🔁.

## 5. Закрой урок

Чеклист «После занятия» из CLAUDE.md, целиком: разбор в `personal/reviews/` →
`personal/progress.md` → `personal/mistakes.md` (рецидивы помечай, заметки
«на будущее» — например к ещё не пройденному модулю — сохраняй отдельной строкой) →
коммит только общих файлов (новый файл урока), без баллов в сообщении → сброс
`personal/state.md` в «между уроками» с указанием следующей темы.
